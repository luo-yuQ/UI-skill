- 仓库审计结论：`game-ui-auto-composer-skill/scripts/toapis_preview_adapter.py` 的 `upload_image` 就是历史上传合约来源（POST `https://ai-api.youchu.work/api/upload`，multipart `files={"file": (name, file)}`，Bearer 认证，响应 `data.url` → `transfer-hk.youchu.xyz/d/xxx.png`；测试 test_upload_uses_confirmed_multipart_contract 明确验证）。

- `image2_cli.py` 已改为：本地校验 → 逐张 /api/upload（显式 MIME）→ images=[URL,...] → submit/poll/result/download。request.json 存 `{local_path, url}` 审计结构；发送 payload 只含纯 URL 字符串。所有错误信息经 api_key redact。
