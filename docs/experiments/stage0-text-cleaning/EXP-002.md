# EXP-002 Red Overlay + Strong Prompt

## 目的

在 source、OCR、VLM 判断、red overlay、model 和尺寸规则全部不变时，只强化 Image-2 Prompt，判断文字残留是否主要来自 Prompt 约束不足。

## 背景

EXP-001 使用脚本内置 `SOURCE_PLUS_OVERLAY_PROMPT`。如果 `999`、`12345/12345` 仍被保留，需要先排除“仅仅是 Prompt 不够强”的可能性。

## 假设

如果问题主要来自 Prompt 约束不足，那么 red overlay 不变时，strong Prompt v2 应减少目标数字残留，且不显著增加背景破坏或非目标区域变化。

## 固定条件

- source image：复用 EXP-001 的 `shared/source.png`
- OCR result：复用 EXP-001 的 `ocr/texts.json`
- VLM result：复用 EXP-001 的 `regions/vlm-region-plan.json`
- red overlay：复用 EXP-001 的 `regions/region-mask-overlay.png`
- VLM model / padding：继承 EXP-001，不重新执行 VLM
- Image-2 model：`gpt-image-2`
- Image-2 size：与 EXP-001 使用相同自动映射规则
- 其他 Image-2 CLI 参数：保持默认值
