# EXP-004 Local Glyph Destruction

## 目的

验证在 Image-2 前先按 EXP-003 的同一 binary mask 本地破坏文字 glyph，是否能降低模型从原始视觉信息中重建 `999`、`12345/12345` 的概率。

## 背景

即使第二张参考图明确指出删除区域，第一张原图仍完整包含字符形状。Image-2 可能把这些形状当成应保留内容。本实验需要在不改变区域、Prompt、model 和尺寸规则的前提下破坏这部分视觉证据。

## 假设

如果文字重现主要因为第一张参考图仍含完整 glyph，那么使用同一 mask 生成的本地预清除图作为第一张参考图后，文字残留应比 EXP-003 减少。

## 固定条件

- 原始 source：与 EXP-001～003 相同，仅用于生成预清除图和人工对照
- OCR / VLM result：复用 EXP-001
- binary mask：逐字节复用 EXP-003 的 `region-mask.png`
- strong Prompt：逐字节复用 EXP-002/003
- 第二张普通 reference image：仍是 EXP-003 的 `region-mask.png`
- Image-2 model：`gpt-image-2`
- Image-2 size 规则及其他参数：与 EXP-003 相同
- 本地预处理必须只改变 mask 内像素，输出尺寸必须与 source 完全一致

## 本次变量

唯一主要变量应当是：

```text
Image-2 第一张参考图：原始 source.png
→ 按同一 region-mask.png 本地破坏 glyph 后的 precleared.png
```

具体 glyph destruction 算法一旦确定，必须记录版本和参数；同一 EXP 不得混合多种算法。
