# EXP-001 Red Overlay Baseline

## 目的

建立现有方案的基线：原始截图作为第一张参考图，VLM 生成的红色区域标记图作为第二张参考图，使用 `ui_image_clean_repair_poc.py` 的内置 overlay Prompt 调用 Image-2。

## 背景

Image-2 有时会保留本应删除的文字，例如 `999`、`12345/12345`。必须先固定当前 red overlay 方案的结果，后续 Prompt、binary mask 和本地 glyph destruction 才有可比较基线。

## 假设

当前 red overlay + 内置 Prompt 能删除多数普通 UI 文字，但可能因为约束不足或第二张图存在视觉歧义而保留部分数字。

## 固定条件

- source image：`runs/stage0-text-cleaning/shared/source.png`
- OCR：`ui_text_extractor.py` 当前实现；四个显式输出路径固定
- VLM：`ui_vlm_region_mask_poc.py`
- VLM model：`gpt-5.6-terra`
- region padding：`0 px`
- Image-2 model：`gpt-image-2`
- Image-2 size：由 source 方向自动映射；实际值以 `result.json.provider_size` 为准
- prompt 基础版本：`ui_image_clean_repair_poc.py` 内置 `SOURCE_PLUS_OVERLAY_PROMPT`
- 第二张参考图：同一次 VLM pass 生成的 `region-mask-overlay.png`

## 本次变量

无。此实验是后续实验的 baseline。

## 输入文件

- `runs/stage0-text-cleaning/shared/source.png`：原始 UI 截图；当前缺少，运行前必须放置。
- `runs/stage0-text-cleaning/exp-001/ocr/texts.json`：Step 1 生成的 OCR 结果。
- `runs/stage0-text-cleaning/exp-001/regions/region-mask-overlay.png`：Step 2 生成的红色区域标记图。

## CLI

从仓库根目录 `E:\game-ui-skill` 执行。不要把密钥写进实验文档或 `result.json`。

Step 1：OCR

```powershell
python game-ui-asset-extractor/scripts/ui_text_extractor.py `
  --image "runs/stage0-text-cleaning/shared/source.png" `
  --output-json "runs/stage0-text-cleaning/exp-001/ocr/texts.json" `
  --output-mask "runs/stage0-text-cleaning/exp-001/ocr/raw-text-mask.png" `
  --output-cleaned "runs/stage0-text-cleaning/exp-001/ocr/ocr-telea-cleaned.png" `
  --output-debug "runs/stage0-text-cleaning/exp-001/ocr/ocr-debug.png"
```

Step 2：VLM 判断并生成 paired region mask / red overlay

运行前确保当前 PowerShell 会话已有 `OPENAI_BASE_URL` 与 `OPENAI_API_KEY`。

```powershell
python game-ui-asset-extractor/scripts/ui_vlm_region_mask_poc.py `
  --image "runs/stage0-text-cleaning/shared/source.png" `
  --texts-json "runs/stage0-text-cleaning/exp-001/ocr/texts.json" `
  --output-dir "runs/stage0-text-cleaning/exp-001/regions" `
  --model "gpt-5.6-terra" `
  --padding-px 0
```

Step 3：Image-2 baseline

运行前确保当前 PowerShell 会话已有 `TOAPIS_API_KEY`。

```powershell
python game-ui-asset-extractor/scripts/ui_image_clean_repair_poc.py `
  --image "runs/stage0-text-cleaning/shared/source.png" `
  --mask-overlay "runs/stage0-text-cleaning/exp-001/regions/region-mask-overlay.png" `
  --model "gpt-image-2" `
  --output-dir "runs/stage0-text-cleaning/exp-001/image2"
```
