# Shape Language

## Analyze

Record dominant silhouette, contour, weight, symmetry, geometric/organic, directional, and complexity tendencies.

## Direct observation

Repeated pointed or rounded contours, heavy or slender proportions, symmetry, orientation, and silhouette complexity are directly observable.

## Describe

Select comparable traits and add one short explanation of where they recur, such as “pointed armor plates and narrow towers create a sharp vertical tendency.”

## Common errors

- Describing subject identity instead of shape.
- Promoting one isolated contour to a dominant trait.
- Recommending matching button, panel, or layout shapes.

## Do not analyze

Do not convert shape observations into UI component design rules or page-layout recommendations.
