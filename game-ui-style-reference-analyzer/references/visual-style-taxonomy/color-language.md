# Color Language

## Analyze

Record dominant, secondary, and accent colors plus saturation, value, temperature, contrast, and notable color relationships.

## Direct observation

Visible color areas, relative prevalence, localized accents, and light/dark or warm/cool relationships are observable. Exact color values are observable only when image quality supports them.

## Describe

Use concise relational phrases such as “low-saturation blue-gray fields with localized blue-white accents.” Prefer stable tendency fields over a long palette narrative.

## Common errors

- Listing color names without their relationship or visual weight.
- Inventing precise HEX values from compressed or ambiguous imagery.
- Declaring one image's dominant color to be the whole game's primary color.

## Do not analyze

Do not recommend a UI palette, assign brand colors, or prescribe where colors should be used.
