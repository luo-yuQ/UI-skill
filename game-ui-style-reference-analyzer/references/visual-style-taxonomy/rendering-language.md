# Rendering Language

## Analyze

Record how the image is represented: primary rendering approach, outline strength, texture and surface-detail density, gradient use, and visible brushwork.

## Direct observation

Pixel structure, outlines, modeled shading, brush marks, texture density, gradients, and surface detail are observable. Labels such as semi-realistic or PBR-like summarize those cues.

## Describe

Use one primary rendering category plus concise secondary traits. Keep rendering separate from theme: “semi-realistic digital painting” is rendering; “dark fantasy” is theme context.

## Common errors

- Mixing subject matter or mood into rendering fields.
- Claiming a production pipeline or software from appearance alone.
- Treating image compression artifacts as intentional texture.

## Do not analyze

Do not recommend render engines, shaders, generation models, prompts, or production techniques.
