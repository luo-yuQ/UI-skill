# 示例输入：Sky Vanguard 装备商城

## 输入图片说明

一张虚构游戏 **Sky Vanguard** 的完整横屏装备商城截图。画面顶部显示资源摘要，左侧是装备分类，中部是六张可见商品卡片，右侧展示当前选中装备的较大预览和说明，右下方有高亮操作区。截图右缘轻微裁切，无法确认列表是否还能继续滚动。

## 图片用途

该图片仅作为其他游戏 UI 的布局参考，用于分析页面分区、组件组、重复结构、视觉层级和区域关系。

## 用户关注说明

主要参考分类、商品列表、选中商品详情和购买操作之间的布局关系。

## 期望分析重点

- 先识别整页用途与一级区域；
- 区分类别控制、商品列表和详情更新关系中的观察与推断；
- 记录当前可靠可见的商品卡数量；
- 提取可迁移的列表—详情—主操作布局规律；
- 排除虚构游戏名称、徽标、装备造型、货币图标和原始文案。

## 不属于 A1 的事项

不生成新商城 UI，不切分商品卡或图标，不判断九宫格，不输出图片提示词、引擎节点或具体购买逻辑，也不创建运行目录。
