# 逻辑组件组词汇表

component group 位于 region 和单个控件之间，表达一组共同完成局部任务的元素。不要拆分到每个图标和文本，也不要输出 FairyGUI、Unity、Laya、Cocos 或其他引擎节点类型。重复元素通过 group、`visible_item_count` 和 `repeat_pattern` 表达。

| group 类型 | 典型用途 | 识别提示 | 常见误判 |
| --- | --- | --- | --- |
| `tab_group` | 在同级分类或内容视图间切换 | 多个同形标签有选中/未选中差异 | 不要把互不相关的按钮合为标签组 |
| `card_list` | 以卡片序列展示对象 | 重复卡片沿行、列或轮播排列 | 背景纹样不是卡片列表 |
| `item_grid` | 以规则网格展示物品 | 单元尺寸相近且行列对齐 | 不要把自由散布图标当网格 |
| `resource_group` | 汇总货币、体力等资源 | 图标、数值和可能的增加入口成组 | 单个商品价格不是全局资源组 |
| `filter_group` | 筛选、排序或搜索内容 | 控件共同影响某个列表范围 | 页面主导航不一定是筛选 |
| `reward_group` | 展示一组可领取或已获得奖励 | 奖励图标、数量和状态成组 | 普通库存物品不等于奖励 |
| `action_group` | 组织一组有任务语义的操作 | 主次操作围绕当前对象或步骤 | 不要把相邻但无共同任务的按钮强行合并 |
| `button_group` | 表达纯视觉上成组的多个按钮 | 按钮尺寸、排列与样式一致 | 能判断业务职责时优先用更具体 group |
| `character_showcase` | 组织角色/对象的大尺度展示 | 主形象与名称、状态或切换提示共同构成展示 | 不要把角色轮廓当通用素材规范 |
| `detail_panel` | 组织当前对象的详细信息 | 标题、属性、说明和状态共同出现 | 单个文本框不是详情面板 |
| `status_group` | 汇总局部状态 | 多个状态值共同描述对象或流程 | 全局资源优先使用 `resource_group` |
| `navigation_group` | 组织导航入口 | 返回、分类或页面入口有一致导航职责 | 操作按钮不因位于顶部就属于导航 |
| `progress_group` | 表达进度、阶段或里程碑 | 进度条、节点、当前值和目标值成组 | 装饰性长条不一定是进度条 |
| `text_information_group` | 组织说明、规则或叙事文本 | 多段文字形成一个信息块 | 不要把每一行文本拆成独立 group |
| `unknown_group` | 记录边界可见但职责不明的逻辑组 | 元素显然成组，功能证据不足 | 不要用具体类型掩盖不确定性 |

一个 region 可以包含多个 component group；一个 group 只归属于一个 region。若界面细节不足，宁可使用较粗的 group，也不要虚构控件级结构。
