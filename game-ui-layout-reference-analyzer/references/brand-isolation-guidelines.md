# 品牌与具体美术隔离

A1 只提取可迁移的布局知识，不把参考截图中的品牌、美术或具体内容转化为可复用素材。本指南不是法律意见。

## 可以参考的布局属性

- 页面分区及其相对占比；
- 主次视觉层级；
- 区域之间的相邻、覆盖、从属和控制关系；
- 组件组的排列方向与密度；
- 重复结构及当前可见数量；
- 主操作在页面中的相对位置；
- 留白、间距和内容密度形成的空间节奏；
- 对象列表、详情展示和操作区之间的抽象协作模式。

将结论写成抽象规则，例如“左侧分类控制中央列表，右侧保留所选对象的详情空间”，而不是要求重现某款游戏的画面。

## 不应继承的内容

- 原游戏名称与 Logo；
- 角色身份、形象和可识别轮廓；
- 具体图标与货币造型；
- 原始文案、专有名词和数值；
- 独有装饰纹样与品牌色组合；
- 受保护或可明确识别来源的视觉识别元素；
- 截图中的任何内容作为可直接复制、裁切或提取的素材。

## 输出要求

1. 在 `layout_rules` 中只记录可参考的结构、关系、密度或层级。
2. 在 `excluded_content` 中记录应隔离的具体内容。
3. 为每个排除项提供 `category`、客观描述与排除原因。
4. 不输出素材提取步骤、图片编辑提示词或替代品牌仿制说明。
5. 无法确认某元素是否具有品牌特征时，保守列入排除项或不确定项。

## 自检问题

- 删除游戏名后，规则是否仍然成立？
- 换成全新角色、图标、文案和配色后，规则是否仍可使用？
- 输出是否在描述布局，而非要求复制画面？
- 是否把角色轮廓、货币图标或独有装饰误称为通用组件？
