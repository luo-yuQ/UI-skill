# 页面一级区域词汇表

region 是页面功能区域，不等同于单个视觉面板，也不等同于引擎节点。先按页面任务、空间连续性和内容职责划分大区域，再分析区域内的组件组。允许使用以 `_region` 结尾的自定义英文类型，但优先使用稳定词汇。

| region 类型 | 用途 | 判断依据 | 常见子内容 | 不应如何误用 |
| --- | --- | --- | --- | --- |
| `background_region` | 承载环境、底图或装饰背景 | 大面积铺底且通常不承担直接操作 | 场景、渐变、纹理、氛围装饰 | 不把装饰图案拆成可交互控件 |
| `global_status_region` | 展示跨页面资源或全局状态 | 位于稳定边缘位置，信息在多个页面复用 | 货币、体力、玩家等级、连接状态 | 不把局部商品价格归入全局状态 |
| `navigation_region` | 在页面、分类或层级间导航 | 含标签、返回、主菜单或分类入口 | 标签组、侧栏、面包屑、返回入口 | 不把所有按钮集合称为导航区 |
| `primary_content_region` | 承载页面主任务内容 | 面积、位置和信息密度均围绕主用途 | 主列表、主画布、任务内容 | 不把整个页面默认归为一个主内容区而遗漏结构 |
| `object_list_region` | 浏览可选对象集合 | 存在重复卡片、网格或行项目 | 商品卡、英雄卡、物品格 | 不猜测被裁切列表的完整总量 |
| `detail_region` | 展示当前对象的详细信息 | 与对象列表或选中状态形成对应 | 名称、属性、说明、预览 | 没有选择对应证据时不要断言由列表控制 |
| `character_showcase_region` | 以较大尺度展示角色或对象形象 | 视觉占比和焦点明显高于普通缩略图 | 角色全身、装备预览、姿态展示 | 不把角色形象视为可复用素材 |
| `filter_region` | 限定、排序或搜索内容集合 | 控件与列表内容范围存在合理关联 | 分类、排序、搜索、筛选标签 | 不把主导航标签误归为筛选区 |
| `primary_action_region` | 承载完成当前主任务的操作 | 高对比、稳定位置或与当前对象紧密关联 | 确认、购买、开始、领取 | 高亮装饰不自动等于主操作 |
| `secondary_action_region` | 承载辅助或低优先级操作 | 视觉权重低于主操作且不完成核心任务 | 返回、预览、比较、重置 | 不因位置靠边就认定为次操作 |
| `modal_region` | 覆盖当前内容的短任务面板 | 有明显前景容器、遮罩或中断上下文 | 确认、提示、奖励、选择 | 不把普通卡片面板当作弹窗 |
| `overlay_region` | 叠加显示而不完全替代底层内容 | 位于更高 z-order，可能透明或局部覆盖 | 遮罩、引导层、浮动提示 | 不把每个阴影或发光效果当覆盖区 |
| `notification_region` | 提供临时状态或消息反馈 | 内容短暂、边缘化或独立于主任务 | toast、红点摘要、系统提示 | 邮件或任务列表不等于通知区 |
| `unknown_region` | 记录无法可靠确定职责的大区域 | 可见区域明确但功能证据不足 | 未知面板、模糊遮挡区 | 不用具体功能名称包装猜测 |

划分时优先保证一级区域互相有清晰职责。视觉边框可以帮助判断边界，但不能单独决定 region 数量。
